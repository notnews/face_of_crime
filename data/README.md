# Data

`raw/ci`, `raw/lo`, and `raw/svu` hold the original episode coding sheets. The six CSV inputs used by the original scripts represent 194 *Criminal Intent*, 151 original-series, and 386 *SVU* rows. The additional `law_and_order_svu.csv` is an incomplete 385-row template: only 23 rows have episode titles, so it is preserved but not used. Each analysis row is a coded episode or combined episode entry; it is not a person. The `n_victims` and `n_criminals` fields can be nonnumeric or missing. Analysis percentages use counts parsed from the race or gender fields and exclude unclassified characters from each denominator.

`reference/` contains Census population shares, FBI Uniform Crime Reports arrest and murder-victim data, National Crime Victimization Survey data, and New York City enforcement shares. The archived CSVs are the historical analytical handoffs. The main NCVS figures and annual tables are now rebuilt from the pinned [BJS API response](../docs/ncvs_source.md). UCR arrest and murder-victim results are rebuilt from the archived workbooks, using the annual counts. The NYPD files preserve annual percentages but not the counts needed to pool years; NYPD appears only in the annual supporting tables. Census and NYPD extraction from the source publications remains undocumented. Source files and hashes are listed in [`../docs/source_manifest.csv`](../docs/source_manifest.csv).

`build/` is generated by `make analysis` and ignored by Git. It contains the typed episode and reference tables and the computed results used for the tracked `tabs/` CSVs and `figs/` PDFs.

In the main figures, a show's reference percentage pools counts over the intersection of that show's coded broadcast years and the reference's available years. The early original-series episodes (1990–1992) have no NCVS or UCR observations; its benchmark uses 2005–2010. NCVS uses the series-adjusted survey weight, UCR uses its race, sex, or ethnicity count denominator, and murder-victim shares use all recorded victims, including those with unknown race or sex in the denominator. UCR ethnicity counts start in 2013 and cover only arrests with reported ethnicity, so only SVU has a matched UCR Hispanic comparison. NCVS offender sex is victim-reported and refers to incidents, not distinct offenders. The annual supporting tables show year-specific percentages, not pooled values.

## Coding rules

- Race: `white`, `black`, `hispanic`, and `asian` are counted as mutually exclusive categories, following the source sheets. `unknown`, `mixed`, and other unclassified labels are excluded from known-race denominators.
- Gender: `male` and `female` are counted as written. An asterisked `Female*` entry is retained as unclassified pending a coding decision; its source note says `*Transgender`.
- Comma-separated labels may include an explicit count (`2 black`) or a single unnumbered label (`Black`). Extra whitespace, plurals, and a missing space in `1hispanic` are parsed. The source values remain unchanged.
- The “Mushrooms” row in the original series has race and gender labels in each other’s columns for both roles. The reader corrects that one transposition without changing the source file.
- An episode can appear in both the murder and rape subsets if its crime field contains both words. Annual estimates pool classified characters in the coded episodes broadcast that year.

The [coding discrepancy table](../docs/coding_discrepancies.csv) lists rows whose classified race or gender count exceeds the stated number of victims or criminals. The audit also records duplicate episode identifiers and missing declared totals. These cases remain in the published source files; the pipeline does not infer replacements for ambiguous counts or identifiers.
