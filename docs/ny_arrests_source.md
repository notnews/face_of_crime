# NYPD female rape arrest reference

The [NYPD Arrests Data (Historic)](https://data.cityofnewyork.us/Public-Safety/NYPD-Arrests-Data-Historic-/8h9b-rp9u) contain arrest date, offense, and arrestee sex. On 2026-10-23, `scripts/01_download_nypd_rape_arrests.R` queried the official [Socrata API](https://dev.socrata.com/docs/queries/group) for annual counts by `perp_sex` when `ofns_desc = 'RAPE'` and `arrest_date` was in 2008–2015. The aggregate response is pinned in [`rape_arrests_by_sex_2008_2015.csv`](../data/reference/ny_arrests/rape_arrests_by_sex_2008_2015.csv), with its SHA-256 in [`source_manifest.csv`](source_manifest.csv). Run the script from the repository root to refresh the response; the committed snapshot keeps the paper reproducible if the live dataset changes.

The snapshot has 151 female and 6,492 male rape arrests: 2.27% female. Each annual API total differs by no more than five arrests from the corresponding archived NYPD enforcement report total. The small differences can arise because the current historical dataset has been revised since those reports were compiled; they prevent treating the API extract as an exact reconstruction of the reports. The figure labels this reference **NYPD rape arrests**, distinct from the NYPD rape *suspect* race/ethnicity percentages in the archived reports.

The current API's homicide arrest count differs substantially from the archived report: 858 versus 308 in 2015. We do not use a female homicide arrest estimate from this API. The archived enforcement reports do not contain victim or suspect sex tables, and the historical complaint file does not reproduce their offense totals closely enough for a comparable female victim or suspect dot.
